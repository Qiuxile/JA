## 本书适用的C++标准

本书基于 **ISO/IEC 14882:2011**（即C++11）标准编写，涵盖：

- C++11 新增特性（auto、范围for、Lambda、智能指针等）
- C++98/03 的核心内容
- STL（标准模板库）的全面介绍

## 推荐阅读顺序

1. **入门阶段**：第1-6章 → 掌握基本语法和流程控制
2. **进阶阶段**：第7-9章 → 函数、内存管理
3. **OOP核心**：第10-14章 → 类、继承、多态、模板
4. **高级应用**：第15-18章 → 异常、STL、新标准特性
