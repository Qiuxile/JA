# 附录H 精选读物和网上资源



## 本章概述

本附录推荐C++学习的精选书籍和网上资源，帮助读者进一步深入学习。


## H.1 精选读物

### C++入门书籍

| 书名 | 作者 | 说明 |
|------|------|------|
| 《C++ Primer》 | Stanley B. Lippman 等 | 适合有C语言基础的读者 |
| 《C++ Primer Plus》 | Stephen Prata | 本书，适合初学者 |
| 《Accelerated C++》 | Andrew Koenig 等 | 实用导向，适合有编程经验者 |
| 《Programming: Principles and Practice Using C++》 | Bjarne Stroustrup | C++之父的入门教材 |

### C++进阶书籍

| 书名 | 作者 | 说明 |
|------|------|------|
| 《Effective C++》 | Scott Meyers | 55条有效编程建议 |
| 《Effective Modern C++》 | Scott Meyers | C++11/14的有效建议 |
| 《More Effective C++》 | Scott Meyers | 35条进阶建议 |
| 《Exceptional C++》 | Herb Sutter | 异常安全和设计 |
| 《Modern C++ Design》 | Andrei Alexandrescu | 模板和泛型编程 |

### STL和算法

| 书名 | 作者 | 说明 |
|------|------|------|
| 《The C++ Standard Library》 | Nicolai M. Josuttis | STL权威参考 |
| 《STL源码剖析》 | 侯捷 | 深入STL实现 |
| 《Introduction to Algorithms》 | Cormen 等 | 算法经典 |

### 面向对象和设计模式

| 书名 | 作者 | 说明 |
|------|------|------|
| 《Design Patterns》 | GoF | 设计模式经典 |
| 《Object-Oriented Software Engineering》 | Ivar Jacobson | 面向对象方法 |
